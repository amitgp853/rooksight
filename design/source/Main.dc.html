Rooksight piece set · 48-unit SVG grid · drawn at 90% of the square, centred
Pieces · flat silhouettes A custom SVG set on a 48-unit grid, every piece standing on the same plinth so the row reads level. Drawn at 90% of the square and optically centred. White is porcelain with a 1.5 px ink outline; black is ink with a pale rim so it holds on dark squares.
Board · full-bleed, always On every chess screen the board spans the full screen width (390 → 48.75 px squares). Coordinates sit inside the edge squares so no gutter is spent on them.
Overlays Last move: brass tint on both squares. Selected: focus-blue fill; legal moves: dots, captures: rings. Hint: brass arrow. Best move in review: focus-blue ring. Check: coral glow. Quality badge: symbol disc, top-right.
Themes Four themes, all cool-to-neutral except Ember. The last-move tint and overlays stay the same across themes so meaning never shifts.
